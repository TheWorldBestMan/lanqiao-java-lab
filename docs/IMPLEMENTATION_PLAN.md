# LanQiao Java Lab 阶段性实现方案

## 产品目标

让 Java 初学者用清晰的知识路径完成“学概念、做题、看反馈、复习错题、参加模拟、复盘薄弱点”的训练闭环，同时将题目版权和远程代码执行风险纳入产品设计。

## 阶段 1：可运行 MVP（当前）

1. 建立 Vue 3 与 Spring Boot 单仓库工程。
2. 提供知识树、题库筛选、题目详情、Monaco 编辑器与提交结果。
3. 建立 MySQL/Flyway 模型和 Redis 限流接入点。
4. 对接 Judge0 服务端 API；Judge0 不可用时禁止任何本地执行回退。
5. 提供错题本、模拟考试、学习分析和后台治理的 MVP 页面/接口。
6. 只使用原创演示题；第三方题目采用元数据占位与授权状态控制。

验收标准：前端可构建，后端测试通过；配置 MySQL、Redis 后可启动；配置 Judge0 后可安全提交 Java 代码。

## 阶段 2：学习闭环增强

- 账户与 RBAC：学生、教师、管理员。
- 知识点内容、分步提示、题目标签与先修关系后台维护。
- 提交异步队列、WebSocket 状态推送、测试点级反馈。
- 自动错题归因、间隔复习、每日任务和个性化推荐。
- 模拟考试计时、防误交、自动保存、考试后报告。

## 阶段 3：运营与内容治理

- 题目导入审核流、授权凭证、下架与审计日志。
- 班级、训练营、榜单和教师看板。
- Judge0 独立集群、队列削峰、配额、告警与成本监控。
- 埋点指标：首题完成时间、周留存、知识点掌握增益、模拟考试提升。

## 安全边界

- 浏览器永远不直接访问 Judge0；所有调用经后端固定地址代理。
- 禁止用户控制 Judge0 主机、语言 ID、编译参数、回调地址和资源上限。
- 源码、标准输入与输出均限制长度；提交接口做身份级速率限制。
- Judge0 与业务数据库分网部署，不挂载宿主敏感目录，不开放公网管理端口。
- 不记录密钥；生产日志避免保存完整用户源码与测试数据。

## 版权边界

- `ORIGINAL`：可完整展示自研题面和题解。
- `AUTHORIZED`：仅在授权范围内展示，并记录授权依据。
- `LINK_ONLY`：仅展示标题、平台、外部编号和跳转链接。
- `METADATA_ONLY`：只做学习计划占位，不提供题面、样例或测试数据。
- `RESTRICTED`：不可发布，后台可见。
